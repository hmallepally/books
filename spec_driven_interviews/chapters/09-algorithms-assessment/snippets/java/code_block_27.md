```java
Queue<Integer> queue = new LinkedList<>();
queue.offer(1);            // Enqueue — O(1)
queue.offer(2);
queue.peek();              // View head (returns 1) — O(1)
queue.poll();              // Dequeue (removes 1) — O(1)
queue.isEmpty();           // Check if empty
queue.size();              // Current element count
```
