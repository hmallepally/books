# Image Creation Guide for "Living Strategy" Book

This guide provides detailed specifications for creating print-friendly images for each chapter's "What Changed" section. All images should be:

- **Print-friendly**: High resolution (300 DPI minimum), black and white or grayscale
- **Professional**: Clean, minimalist design suitable for business publication
- **Conceptual**: Illustrate the key transformation described in each "What Changed" section
- **Consistent**: Use similar visual style and design elements throughout

## Image Specifications

- **Format**: PNG or SVG (for scalability)
- **Resolution**: 300 DPI minimum for print
- **Color**: Black and white or grayscale
- **Size**: 6" x 4" (portrait) or 8" x 5" (landscape) depending on content
- **Style**: Clean, minimalist, professional business diagrams

## Additional Chapters (11-70)

For chapters 11-70, follow the same pattern:

1. **Identify the key transformation** in the "What Changed" section
2. **Create a before/after visual** showing the evolution
3. **Include relevant symbols** that represent the concept
4. **Maintain consistent style** with the established design language

### Common Visual Elements to Use:

- **Arrows**: For transformation, direction, flow
- **Networks**: For connections, ecosystems, relationships
- **Clocks**: For time compression, cycles, cadence
- **Shields**: For protection, moats, resilience
- **Scales**: For balance, trade-offs, equilibrium
- **Compasses**: For guidance, direction, vision
- **Loops**: For feedback, learning, iteration
- **Pyramids**: For hierarchy, structure, foundation
- **Waves**: For change, disruption, adaptation

### Design Principles:

1. **Simplicity**: Clean, uncluttered designs
2. **Clarity**: Easy to understand at a glance
3. **Consistency**: Similar visual language throughout
4. **Professional**: Suitable for business publication
5. **Print-friendly**: High contrast, clear lines

---

## Implementation Notes

- Each image should be created as a separate file named: `chapter_[number]_what_changed.png`
- Store all images in the `images/` folder
- Consider creating a master template with consistent fonts, colors, and styling
- Test images at print resolution to ensure clarity
- Provide both PNG and SVG versions for flexibility

This guide ensures that all images will be professional, consistent, and effectively illustrate the strategic transformations described in each chapter.
